# BASE44 ICON SYSTEM MASTER PROMPT

> **Komplettes Icon-System der Website vereinheitlichen — Senior SaaS UI/UX Designer**

---

## ROLLE

Die Website wurde bereits erstellt.

Deine Aufgabe ist es, das **komplette Icon-System** der Website zu vereinheitlichen.

Arbeite wie ein **Senior SaaS UI/UX Designer**.

Das Ziel ist ein **modernes, minimalistisches und professionelles** Erscheinungsbild.

---

**Alle Emojis müssen durch professionelle SVG-Icons ersetzt werden.**

---

## ICON-STYLE

Verwende **ausschliesslich einen einzigen Icon-Stil** auf der gesamten Website.

Nicht mischen.

Alle Icons müssen sein:

- Modern
- Minimalistisch
- Dünne Linien (Outline Style)
- Einheitliche Strichstärke
- Runde Ecken
- Hochwertige SVG-Icons
- Zeitloses SaaS-Design

> **Keine bunten Icons. Keine 3D-Icons. Keine Illustrationen. Keine Emoji-ähnlichen Icons.**

---

## EMPFOHLENE ICON-BIBLIOTHEK

Verwende **ausschliesslich eine** dieser Bibliotheken:

- **Lucide Icons** (bevorzugt)
- Heroicons
- Tabler Icons

> **Keine Mischung verschiedener Bibliotheken.**
